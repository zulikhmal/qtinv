# Quotation & Invois Pantas Terus ke WhatsApp

A lightweight Node.js and Tailwind CSS web application designed to generate professional Quotations and Invoices, export them directly to PDF using `html2canvas` and `jsPDF`, and send automated notification messages with PDF attachments directly to WhatsApp.

## Features
- **Live Preview:** See changes update instantly as you type client details and line items.
- **Client-Side PDF Rendering:** Generates clean, high-resolution PDF documents instantly in the browser.
- **Direct WhatsApp Integration:** Formats custom message text containing total amounts and document references and triggers WhatsApp Web/App delivery.
- **Netlify & GitHub Ready:** Easily deployable as a static/serverless site.
